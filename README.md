
# Honzawa-Ryu

東京大学大学院薬学系研究科 分子薬物動態学教室
[水野班（Mizuno Group）](https://www.mizuno-group.com/about/)に所属しています。

病理画像解析の研究に取り組んでいます。

## 公開プロジェクト

### [wsi_preprocess](https://github.com/Honzawa-Ryu/wsi_preprocess)
病理画像の前処理ツール。
TRIDENTを使ったパッチ座標・特徴量の抽出に加え、
ぼやけの評価や学習用データセットの作成を行います。

### [agent-research](https://github.com/Honzawa-Ryu/agent-research)
AIエージェントを活用した文献調査の作業場所。
論文、調査レポート、研究アイデアを整理しています。
